# VastraCommerce Admin

**Enterprise Commerce Platform**

Modern, scalable, and production-ready enterprise admin panel for managing products, inventory, customers, orders, payments, marketing, CMS, analytics, and system administration.

---

## 🚀 Overview

VastraCommerce Admin is a feature-rich enterprise administration portal built for modern eCommerce businesses. It provides a centralized platform to manage every aspect of an online store—from catalog management to business intelligence—using a clean, modular, and scalable architecture.

Designed with enterprise best practices, the platform delivers high performance, security, and maintainability while providing an exceptional user experience.

# 🚀 Getting Started

## Prerequisites

* Node.js 22+
* pnpm 10+
* Git

## Installation

```bash
git clone https://github.com/your-org/vastracommerce-admin.git

cd vastracommerce-admin

pnpm install
```

## Environment Variables

Create a `.env.local` file:

```env
NEXT_PUBLIC_API_URL=http://localhost:4000/api/v1
```

## Start Development

```bash
pnpm dev
```

Open:

```text
http://localhost:3000
```
